OptiVis - Fabric client mod source project
Target: Minecraft 1.21.11, Java 21

BUILD ON WINDOWS
1. Install JDK 21.
2. Install Gradle (8.14.x recommended) and ensure `gradle` works in CMD.
3. Open CMD in this folder.
4. Run: gradle build
5. Output: build\libs\optivis-1.0.0.jar

Then copy the JAR into .minecraft\mods alongside a compatible Fabric Loader and Fabric API.
